## 🔭 我在做什么

目前是一名**应用算法实习生**，主要参与视频、图像与文本相关业务的算法微服务开发，同时探索大模型后训练与智能体系统。

主要实践与探索：

- **多模态应用** — 面向视频、图像与文本相关业务，开发算法微服务，将模型能力接入实际业务流程。
- **后训练与推理** — 通过监督微调（SFT）、偏好学习与推理相关实验，探索训练方法如何影响模型行为和任务表现。
- **智能体系统** — 关注智能体运行框架（Agent Harness）、环境、记忆与评测，探索这些模块如何共同影响任务完成效果。

我关心模型在实验中的提升，也关心这些提升能否转化为系统中稳定、可复现的效果。

## 🌱 我的理念

我喜欢把后训练、工具调用、智能体环境、记忆和评测放在同一个系统里思考，看看它们会怎样相互影响。

有些想法起初只是“胡思乱想”，不一定正确，也不一定马上有用。我会先记下来，再拆成小实验，用代码、数据和指标检验，在结果里寻找下一步值得追问的问题。

想学的东西很多，路还是要一步一步走。

看见好的代码就读，看见高的地方就爬。  
不找借口，不抄近道。

**日拱一卒，功不唐捐。**
