## 🚀 My Philosophy

有时候会觉得自己挺浮躁的。想学的东西太多，进展又总是达不到预期；看着同龄人发 paper、做项目、拿 offer，心里难免会急。但急归急，路还是得一步一步走。

我的现实很普通：一个 2028 届本科生，接触 LLM 算法领域还不到一年，代码能力和算法思维都还在爬坡。对 post-training、agent harness、agent memory 这些方向，现在更多是“知道一点、正在补”，远谈不上精通。

不过我发现，自己有个比较想保留下来的习惯：把看似不相干的模块放在一起想。后训练、Agent 环境、记忆、评测、工具调用，单独看像是不同问题；放到一个系统里时，偶尔会冒出一些“胡思乱想”。它们不一定马上正确，也不一定马上有用，但我往往会先记下来，再拆成小实验，用代码、数据和指标去验证。

看见好的代码就读，看见高的地方就爬。不找借口，不抄近道。日拱一卒，功不唐捐。试一试吧，总会有收获。

我还是很想进大厂做 LLM 算法工程师，也想慢慢成为一个能做出有价值 AI 系统的人。AGI 还没来，ASI 更远，可这些问题本身就足够吸引我，值得把时间和精力投进去。
