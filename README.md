## 🔭 What I'm Working On

I'm an **Applied AI Algorithm Intern**, primarily developing algorithm microservices for business applications involving video, images, and text. Alongside this work, I explore LLM post-training and agent systems.

My work and areas of exploration:

- **Multimodal Applications** — Developing algorithm microservices for video, image, and text applications, integrating model capabilities into real business workflows.
- **Post-training & Reasoning** — Exploring how training methods affect model behavior and task performance through experiments with SFT, preference learning, and reasoning.
- **Agent Systems** — Exploring agent harnesses, environments, memory, and evaluation, and how their interactions affect task completion.

I care about improvements in experiments and whether they translate into reliable, reproducible results in working systems.

## 🌱 My Philosophy

I like thinking about post-training, tool use, agent environments, memory, and evaluation as parts of one system, and seeing how they influence one another.

Some ideas start as little more than “what if?” They may be wrong, and they may not be useful right away. I write them down, turn them into small experiments, and test them with code, data, and metrics. The results help me find the next question worth asking.

There is a lot to learn, and the path still has to be walked one step at a time.

I read good code when I find it, and I climb when I see higher ground.  
No excuses, no shortcuts.

**A small step every day. No honest effort is wasted.**
